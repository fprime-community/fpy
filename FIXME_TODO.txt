==============================================================================

[x] T2.1  Settled the shadowing / name-collision rule uniformly across all THREE
          sites. DECISION (user): a same-scope duplicate stays a hard ERROR; any
          CROSS-scope shadow (an inner definition hiding an outer/global/base
          name) is a WARNING, categorized by the shadowed name group:
            - shadow-value    (WarningType.SHADOW_VALUE)    -- value group
            - shadow-callable (WarningType.SHADOW_CALLABLE) -- callable group
          Imports fold in by name group (an import binding a callable over a
          builtin -> shadow-callable, etc.).

          Applied at all three sites, uniformly: get() = same scope -> error;
          else lookup() up the parent chain -> shadow warning, then define.
            - semantics.py DefineFunctions.visit_AstDef   (functions).
            - semantics.py DefineVariables.define_variable (variables).
            - imports.py BindImports._bind_symbol + _bind_module (imports; BOTH
              carried the same collision check, so both were updated).
          Removed FIXMEs: the 3 shadowing sites + a follow-up "check all name
          groups?" on _bind_symbol (answered in-code: a bound symbol occupies
          exactly one name group today -- a re-exported module holds only
          functions -- so the loop runs once; kept only to mirror _bind_module).

          SPEC.md: added a "## Shadowing" section; reworded the variable /
          function definition + import-collision semantics; added *Tests:* links.

          Tests: new TestShadowWarnings (variables, functions) + TestImportShadows
          Builtins / TestImportedSequenceShadowingBuiltins (imports). Flipped the
          old "imported sequence cannot shadow a builtin" ERROR-tests to expect
          the warning instead.

          Test-infra change (user-requested): the compile helpers now promote
          EVERY warning to a hard error BY DEFAULT. Pass expected_warnings={...}
          to allow AND require specific ones (a stray/accidental shadow now fails
          the test). Fixed all fallout (loop-var + seq-param shadows, empty-range,
          import-underscore, a README example) by declaring expected warnings.

          Drive-by: added TestImportFrom::test_from_import_reexported_module (the
          `from lib import <module lib itself imported>` re-export path was
          untested); fixed a syntax error a prior commit left in a
          test_functions.py test name (was breaking that file's collection).
